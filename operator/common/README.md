## 公共脚本与函数

### `common.sh`

- 运行位置：代码编译节点或服务部署节点
- 运行方式：不直接执行，由其他 Bash 脚本 `source` 调用
- 输入参数：无独立命令行参数
- 配置文件：由调用脚本传入；可读取 WebDAV、模块列表等配置
- 作用：提供日志初始化、模块列表加载、WebDAV 配置、制品版本解析、文件传输辅助等通用函数
- 日志文件：由 `init_log_file` 设置为调用脚本对应的 `/opt/logs/*.log`

### `transfer_file.sh`

- 运行位置：代码编译节点或服务部署节点
- 运行方式：通常由备份脚本调用，也可手动执行
- 输入参数：`upload <绝对文件路径>` 或 `download <本地目录>`
- 配置文件：`.env`，或由 `WEBDAV_FILE_ENV_FILE` 指定的环境文件
- 作用：使用 WebDAV 凭据上传单个文件，或下载远端目录中的全部文件
- 日志文件：`/opt/logs/transfer-file.log`
