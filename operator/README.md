# 脚本规划

此目录用于存放运维相关脚本。

## 目录说明

### `common/`

规划为公共函数、可复用脚本放在该目录下。


### `upgrade/`

升级所需的相关脚本统一放在该目录下。

### `monitor/`

服务监控的相关脚本统一放在该目录下。

### `change-log/`

版本变更说明相关脚本统一放在该目录下。

### `dingtalk-notify/`

钉钉通知相关的脚本统一放在该目录下。

### `feishu-notify/`

飞书通知相关的脚本统一放在该目录下。


### `backup-config/`

配置文件备份相关的脚本统一放在该目录下。


### `backup-database/`

数据库备份相关的脚本统一放在该目录下。
